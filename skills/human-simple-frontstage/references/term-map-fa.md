# Persian Frontstage Term Map

This is a decision guide, not a fixed dictionary.

Never replace a term mechanically. First ask what the user needs to understand or do in that exact surface.

## Product, marketing, and UX

| Backstage term | Avoid as default | Frontstage options | Use when |
|---|---|---|---|
| Funnel | قیف فروش | «مراحل رسیدن از آشنایی تا خرید» or omit it | Usually keep backstage only |
| Lead | لید | «درخواست»، «اطلاعات تماس»، «کسی که درخواست داده» | Match the real action |
| Conversion | تبدیل | «ثبت درخواست»، «خرید»، «شروع دوره» | Name the actual outcome |
| CTA | فراخوان به اقدام | Keep backstage; frontstage is the button itself | Never explain the term to users |
| Diagnostic | تشخیص هوشمند | «ببین از کجا شروع کنی»، «چند سؤال برای شناخت تو» | Use the user benefit, not the system label |
| Personalization | شخصی‌سازی | «متناسب با نیاز تو»، «برای شرایط خودت» | Only if the product really adapts |
| Activation | فعال‌سازی | «اولین قدمت رو بردار»، «شروع کن» | Name the first meaningful action |
| Onboarding | آنبوردینگ | «شروع کار»، «راه‌اندازی اولیه»، «بیا با هم شروع کنیم» | Match the actual first-use flow |
| Flagship | پرچم‌دار | «برنامه اصلی»، «دوره اصلی» | Keep simple; do not expose portfolio jargon |
| Value proposition | ارزش پیشنهادی | «چرا این به درد تو می‌خوره» | Mostly backstage |
| Segment | سگمنت | «گروه مخاطب»، «آدم‌هایی که…» | Explain the shared situation |
| Journey | سفر کاربر | «مراحل کار»، «از شروع تا نتیجه» | Use only when a sequence matters |
| Touchpoint | نقطه تماس | Name the actual place: «صفحه»، «پیام»، «تماس» | Keep backstage otherwise |
| Retention | نگهداشت | «برگشتن کاربر»، «ادامه دادن» | Name the observable behavior |
| Churn | ریزش | «نیمه‌کاره رها کردن»، «برنگشتن» | Use the real user behavior |
| Proof | اثبات اجتماعی | «نتیجه هنرجوها»، «نمونه کار»، «نظر مشتری» | Name the evidence type |
| Offer | آفر | «پیشنهاد»، «بسته»، «دوره»، «خدمت» | Choose the actual thing sold |
| Premium | پریمیوم | «سطح بالاتر»، «اختصاصی»، or explain the benefit | Do not use as empty status language |
| Early access | دسترسی زودهنگام | «قبل از انتشار عمومی امتحانش کن» | State what early means |
| Beta | بتا | «نسخه آزمایشی» | Keep Beta only for technical audiences |

## AI and technical concepts

| Backstage term | Avoid as default | Frontstage options | Decision rule |
|---|---|---|---|
| Workflow | ورک‌فلو | «مراحل کار»، «روال کار»، «کاری که قدم‌به‌قدم انجام می‌دی» | Choose based on complexity |
| Automation | اتوماسیون | «کارهایی که خودکار انجام می‌شن» | Mention the actual task when possible |
| AI agent | ایجنت هوش مصنوعی | «دستیار هوش مصنوعی» | Explain its job, limits, and required approval |
| Prompt | فرمان متنی | «پرامپت» plus a one-time explanation such as «متنی که به AI می‌دی» | Keep the known term for AI-aware audiences |
| Model | مدل | «مدل هوش مصنوعی» | Add the category only when ambiguity exists |
| API | رابط برنامه‌نویسی کاربردی | «اتصال فنی بین دو سرویس» | Keep API for technical users; explain outcome for others |
| Integration | یکپارچه‌سازی | «وصل کردن دو ابزار»، «اتصال» | Name both systems when useful |
| Token | توکن | Explain the relevant meaning: «واحد مصرف متن» or «کلید دسترسی» | Token has multiple meanings; never guess |
| Context window | پنجره زمینه | «حجمی از متن که مدل هم‌زمان می‌تونه در نظر بگیره» | Use only when the limit changes a decision |
| Fine-tuning | تنظیم دقیق | «آموزش اختصاصی مدل با نمونه‌های خودت» | Do not imply it is always needed |
| RAG | راگ | «پاسخ دادن با استفاده از فایل‌ها و اطلاعات خودت» | Keep acronym backstage for ordinary users |
| Multimodal | چندوجهی | «کار با متن، عکس، صدا و ویدیو» | List the actual media |
| Generate | تولید | «بساز» | Prefer the action verb in UI |
| Upload | بارگذاری | «فایل رو اضافه کن» or «آپلود کن» | Match audience familiarity |
| Export | برون‌بری | «خروجی بگیر» | More natural for most Persian users |
| Render | رندر | «ساخت خروجی نهایی» | Keep render for video/design professionals |

## Analytics and privacy

| Backstage term | Avoid as default | Frontstage options | Decision rule |
|---|---|---|---|
| Analytics | آنالیتیکس | «آمار استفاده از سایت» | Name tools only where privacy requires it |
| Event | رویداد | «کلیک»، «ثبت درخواست»، «شروع ویدیو» | Name the measured action |
| Tracking | رهگیری | «بررسی آمار استفاده» | Do not soften privacy meaning inaccurately |
| Consent | رضایت‌نامه | «اجازه»، «انتخاب تنظیمات آمار» | Make accept and decline equally clear |
| Essential only | فقط ضروری | «فقط ضروری» | Explain what remains active when needed |
| Cookie | کوکی | «کوکی» plus plain explanation in privacy text | Do not replace legal terminology entirely |
| Attribution | انتساب | «این درخواست از کجا اومده» | Mostly backstage |
| UTM | یو‌تی‌ام | «برچسب لینک کمپین» | Keep technical identifier in docs, not ordinary UI |
| Session | نشست | «این بار استفاده از سایت» | Use only when needed |
| Page view | بازدید صفحه | «بازدید صفحه» | Already familiar and clear |

## Education and service delivery

| Backstage term | Avoid as default | Frontstage options | Decision rule |
|---|---|---|---|
| Module | ماژول | «بخش»، «فصل» | Match course structure |
| Mission | مأموریت | «تمرین»، «قدم بعدی»، «کاری که باید انجام بدی» | Use Mission only if gamification is intentional |
| Learning path | مسیر یادگیری | «از کجا شروع کنی و بعد چی یاد بگیری» | Avoid repeating «مسیر» until empty |
| Cohort | کوهورت | «گروه این دوره»، «دوره گروهی» | State dates and capacity when relevant |
| Mentoring | منتورینگ | «جلسه بررسی و راهنمایی» | Keep mentoring if audience already uses it |
| Consultation | مشاوره تخصصی | «مشاوره»، «کمک برای تصمیم‌گیری» | Name the problem and expected output |
| Private training | آموزش خصوصی | «آموزش اختصاصی» | Explain that it adapts to the person only if true |
| Assessment | ارزیابی | «بررسی»، «چند سؤال»، «آزمون» | Match what actually happens |
| Certification | سرتیفیکیت | «گواهی پایان دوره» | Do not imply accreditation unless verified |

## Common replacement mistakes

### Mistake 1: literal translation

Backstage:

`Personalized AI Diagnostic`

Weak:

«تشخیص شخصی‌سازی‌شده هوش مصنوعی»

Better, depending on the feature:

«چند سؤال جواب بده تا بفهمی از کجا شروع کنی.»

### Mistake 2: replacing one jargon word with another

Backstage:

`Activation journey`

Weak:

«فرایند فعال‌سازی»

Better:

«حسابت رو بساز و اولین تمرینت رو شروع کن.»

### Mistake 3: hiding an important technical distinction

Backstage:

`The tool stores data locally but syncs after sign-in.`

Too simple and wrong:

«اطلاعاتت ذخیره می‌شه.»

Better:

«قبل از ورود، اطلاعات روی همین دستگاه می‌مونه. بعد از ورود، با حسابت همگام می‌شه.»

## Decision rule

Use this sequence:

```text
What does the term mean here?
→ Why does the user need to know?
→ What decision or action changes because of it?
→ Write that meaning or action in natural Persian.
```

If the term does not help the user decide or act, keep it backstage.
