# نقشه تبدیل اصطلاحات به زبان مخاطب

این فایل فرهنگ لغت ثابت نیست. هر اصطلاح را با توجه به سطح آشنایی مخاطب، جایگاه متن و کار واقعی کاربر تبدیل کن. هدف، ترجمه تحت‌اللفظی نیست؛ هدف این است که مخاطب بفهمد «این برای من یعنی چه؟» و «حالا چه کار کنم؟»

## بازاریابی و محصول

| اصطلاح پشت‌صحنه | معمولاً نگو | گزینه‌های انسانی پیشنهادی |
|---|---|---|
| Funnel | قیف فروش | مسیر آشنایی تا خرید، مراحلی که کاربر طی می‌کند |
| Lead | لید | درخواست، فردی که اطلاعات تماس گذاشته، متقاضی |
| Conversion | کانورژن / تبدیل | ثبت‌نام، خرید، ارسال درخواست، انجام اقدام موردنظر |
| CTA | فراخوان به اقدام | متن دکمه یا کاری که از مخاطب می‌خواهیم؛ در متن نهایی خود اقدام را بنویس |
| Flagship offer | محصول پرچم‌دار | برنامه اصلی، آموزش اصلی، پیشنهاد اصلی |
| Acquisition | اکتساب | جذب مخاطب، آوردن آدم‌های جدید |
| Retention | ریتنشن | ماندن و ادامه‌دادن کاربر، برگشت دوباره |
| Activation | فعال‌سازی | اولین قدم واقعی، شروع استفاده، شروع مسیر |
| Onboarding | آنبوردینگ | شروع کار، آشنایی اولیه، قدم‌های اول |
| Positioning | جایگاه‌سازی | مردم باید تو را با چه چیزی بشناسند |
| Value proposition | ارزش پیشنهادی | دقیقاً چه کمکی می‌کنی و چرا ارزش پرداخت دارد |
| Social proof | اثبات اجتماعی | نتیجه واقعی، نظر مشتری، نمونه کار، تجربه دیگران |
| Personalization | شخصی‌سازی | متناسب با نیاز تو، مخصوص شرایط تو |
| Segmentation | بخش‌بندی | جداکردن گروه‌های مختلف مخاطب بر اساس نیازشان |
| Qualification | ارزیابی صلاحیت | فهمیدن اینکه این خدمت برای چه کسی مناسب است |
| Touchpoint | نقطه تماس | هر جایی که مخاطب با برند روبه‌رو می‌شود |
| Customer journey | سفر مشتری | مسیری که مخاطب از آشنایی تا استفاده طی می‌کند |
| Soft launch | سافت‌لانچ | عرضه محدود اولیه، فروش اولیه برای آزمون و اصلاح |
| Founder edition | نسخه بنیان‌گذار | سری اول، دوره اول، ثبت‌نام اولیه؛ فقط اگر واقعاً چنین نقشی دارد |

## هوش مصنوعی و فناوری

| اصطلاح پشت‌صحنه | معمولاً نگو | گزینه‌های انسانی پیشنهادی |
|---|---|---|
| AI overload | اضافه‌بار هوش مصنوعی | این همه ابزار و آموزش که آدم را سردرگم می‌کند |
| Tool hopping | پرش بین ابزارها | هر روز رفتن سراغ یک ابزار تازه بدون نتیجه |
| Workflow | ورک‌فلو | روال کار، مراحل کار، مسیر انجام کار |
| Automation | اتوماسیون | خودکارکردن کارهای تکراری |
| AI agent | ایجنت هوش مصنوعی | دستیار هوشمندی که چند کار را برایت انجام می‌دهد؛ فقط اگر واقعاً همین قابلیت وجود دارد |
| Prompt engineering | مهندسی پرامپت | درست درخواست‌کردن از هوش مصنوعی، نوشتن دستور بهتر |
| Model | مدل | موتور هوش مصنوعی؛ اگر نام مدل برای تصمیم کاربر لازم نیست، آن را وارد متن نکن |
| Context window | پنجره زمینه | مقدار اطلاعاتی که مدل هم‌زمان می‌تواند در نظر بگیرد |
| Hallucination | توهم مدل | جواب ساختگی یا نادرستی که مدل با اطمینان می‌گوید |
| Fine-tuning | فاین‌تیون | آموزش اختصاصی‌تر مدل با داده مشخص؛ فقط برای مخاطب فنی توضیح بده |
| Multimodal | چندوجهی | کار با متن، عکس، صدا یا ویدیو در یک ابزار |
| API | رابط برنامه‌نویسی | راه اتصال دو سیستم؛ برای مخاطب غیر فنی معمولاً بگو «اتصال مستقیم سیستم‌ها» |
| Integration | یکپارچه‌سازی | وصل‌کردن ابزارها یا سیستم‌ها به هم |
| Generation | جنریشن | ساخت خروجی، تولید تصویر، ساخت ویدیو |
| Iteration | تکرار | اصلاح مرحله‌به‌مرحله تا نتیجه بهتر شود |

## تجربه کاربری و داده

| اصطلاح پشت‌صحنه | معمولاً نگو | گزینه‌های انسانی پیشنهادی |
|---|---|---|
| Diagnostic | تشخیص‌گر | چند سؤال برای شناخت تو، ببین از کجا شروع کنی |
| User flow | جریان کاربر | مراحلی که کاربر انجام می‌دهد |
| Friction | اصطکاک | چیزی که کار را سخت یا کند می‌کند |
| Cognitive load | بار شناختی | مقدار فکری که کاربر باید برای فهمیدن صفحه صرف کند |
| Drop-off | ریزش | جایی که کاربر ادامه نمی‌دهد |
| Error state | حالت خطا | وقتی کاری انجام نشده و باید راه بعدی را نشان دهیم |
| Empty state | حالت خالی | وقتی هنوز چیزی وجود ندارد و باید بگوییم از کجا شروع کند |
| Analytics | آنالیتیکس | آمار استفاده از سایت، اندازه‌گیری رفتار کلی کاربران |
| Event | رویداد | کاری که برای اندازه‌گیری ثبت می‌شود؛ در متن مخاطب معمولاً نامش را نگو |
| Page view | بازدید صفحه | بازشدن صفحه |
| Consent | رضایت | اجازه برای بررسی آمار یا استفاده از داده |
| Session | نشست | مدت حضور کاربر در یک نوبت استفاده |
| Dashboard | داشبورد | صفحه آمار یا مدیریت؛ اگر کاربر اصطلاح را می‌شناسد همان را نگه دار |

## الگوهای تبدیل

### دسته داخلی به نتیجه کاربر

پشت‌صحنه:

«Personalized AI Diagnostic»

جلوصحنه بسته به جایگاه:

- عنوان: «ببین از کجا شروع کنی»
- توضیح: «با چند سؤال می‌فهمیم چه چیزی به کارت می‌آد.»
- دکمه: «شروع کنیم»

### ویژگی به فایده

پشت‌صحنه:

«Workflow automation»

جلوصحنه:

«کارهای تکراری رو بسپار به یک روال خودکار تا وقتت برای کار مهم‌تر آزاد بشه.»

### فرایند به اقدام

پشت‌صحنه:

«Complete onboarding»

جلوصحنه:

«اولین قدمت رو کامل کن.»

## استثناها

- نام ابزار، فایل، مسیر، Event، API، مدل یا استاندارد را وقتی برای اجرا لازم است دقیق نگه دار.
- اصطلاحی را که مخاطب واقعاً می‌شناسد بی‌دلیل فارسی‌سازی نکن؛ یک توضیح کوتاه کافی است.
- در متن تخصصی برای متخصصان، دقت فنی از ساده‌سازی مهم‌تر است؛ اصطلاح را نگه دار و توضیحش بده.
- اگر چند ترجمه ممکن است تصمیم کاربر را عوض کند، حدس نزن؛ Context یا تعریف محصول را بررسی کن.
