# Backstage-to-Frontstage Term Map — Persian

This is a decision aid, not a replacement dictionary. Choose the phrase that matches the user's situation and the actual product behavior. Do not force one translation everywhere.

## How to use this map

For every internal term:

1. Identify what it means **in this exact context**.
2. Identify what the audience needs to know or do.
3. Write that outcome or action in familiar Persian.
4. Keep the original term only when the audience already knows it or precision requires it.

## Product and UX

| Backstage term | Avoid by default | Frontstage possibilities | Choose based on |
|---|---|---|---|
| Diagnostic | تشخیص، دیاگنوستیک | «ببین از کجا شروع کنی»، «چند سؤال برای شناخت تو» | whether it is a quiz, interview, or automated result |
| Personalization | شخصی‌سازی | «متناسب با نیاز تو»، «چیزی که به کارت می‌آد» | whether the product truly adapts |
| Onboarding | آنبوردینگ | «شروع کار»، «قدم‌های اول»، «بیا شروع کنیم» | product stage and tone |
| Activation | فعال‌سازی | «اولین قدمت رو بردار»، «اولین کار رو انجام بده» | the meaningful first action |
| User journey | سفر کاربر | «مراحل کار»، «از ورود تا نتیجه» | whether the user needs to see the sequence |
| Flow | فلو | «مراحل»، «روند»، «روال» | technical vs. audience-facing context |
| Funnel | قیف | «از آشنایی تا خرید»، «مراحل جذب و فروش» | internal documents vs. public copy |
| Touchpoint | نقطه تماس | «جایی که مخاطب با ما روبه‌رو می‌شه» | internal explanation only |
| Conversion | تبدیل | «ثبت درخواست»، «خرید»، «شروع آموزش» | name the actual action |
| Friction | اصطکاک | «چیزی که کار رو سخت می‌کنه» | research or UX explanation |
| Drop-off | ریزش | «کجای مسیر رها می‌کنن» | analytics/reporting context |
| Empty state | حالت خالی | «هنوز چیزی اینجا نیست» plus next action | the actual screen state |
| Progressive disclosure | افشای تدریجی | «هر بار فقط چیزی که لازم داری» | product explanation |
| Feature | فیچر، قابلیت | name the user benefit or action | avoid feature-first copy |
| Flagship | پرچم‌دار | «برنامه اصلی»، exact product name | public offer hierarchy |
| Tier | سطح، پلن | «انتخاب‌ها»، «مدل‌های ثبت‌نام» | pricing context |
| Premium | پریمیوم | «اختصاصی»، «با پشتیبانی بیشتر» | state the real difference, not prestige alone |
| Beta | بتا | «نسخه آزمایشی» | when the user needs the risk context |
| Early access | دسترسی زودهنگام | «زودتر از انتشار عمومی استفاده کن» | be explicit about unfinished parts |

## Marketing and sales

| Backstage term | Avoid by default | Frontstage possibilities | Choose based on |
|---|---|---|---|
| Lead | لید | «درخواست»، «شماره تماس»، «فردی که درخواست داده» | public UI should name the actual object |
| Lead form | فرم لید | «درخواستت رو بفرست»، «اطلاعات تماس» | form purpose |
| Lead magnet | لید مگنت | «آموزش رایگان»، «فایل رایگان»، exact asset | name what the user gets |
| CTA | کال‌تو‌اکشن | actual button label | never expose internally on public UI |
| Campaign | کمپین | «فروش این دوره»، «برنامه معرفی»، «ثبت‌نام این دوره» | audience familiarity |
| Offer | آفر | «پیشنهاد»، «شرایط ثبت‌نام»، exact product | context |
| Value proposition | ارزش پیشنهادی | «چرا این به درد تو می‌خوره» | internal explanation |
| Positioning | جایگاه‌سازی | «می‌خوایم مخاطب ما رو با چی بشناسه» | internal documents |
| Social proof | اثبات اجتماعی | «نظر شرکت‌کننده‌ها»، «نتیجه واقعی» | use evidence, not the label |
| Proof | پروف | «نمونه»، «نتیجه»، «مدرک» | evidence type |
| Retargeting | ریتارگتینگ | «تبلیغ دوباره برای کسانی که قبلاً دیدن» | internal only |
| Acquisition | اکتساب | «جذب مخاطب جدید» | internal report |
| Retention | نگهداشت | «برگشتن و ادامه‌دادن کاربران» | internal report |
| LTV | ارزش طول عمر مشتری | «مجموع خرید یک مشتری در طول زمان» | internal finance |
| Upsell | فروش افزایشی | «پیشنهاد گزینه کامل‌تر» | internal only |
| Cross-sell | فروش مکمل | «پیشنهاد محصول مرتبط» | internal only |
| Scarcity | کمیابی | «ظرفیت محدود» only when real | never fabricate urgency |
| Conversion rate | نرخ تبدیل | «از هر ۱۰۰ نفر، چند نفر اقدام کردن» | make the number interpretable |

## AI and automation

| Backstage term | Avoid by default | Frontstage possibilities | Choose based on |
|---|---|---|---|
| AI workflow | جریان کاری هوش مصنوعی | «مراحل کاری که با AI انجام می‌دی»، «روال کار با AI» | audience familiarity |
| AI agent | ایجنت هوش مصنوعی | «دستیار هوشمند»، then explain what it does | do not imply autonomy it does not have |
| Automation | اتوماسیون | «خودکارکردن کارهای تکراری» | public explanation |
| Prompt engineering | مهندسی پرامپت | «درخواست‌نویسی درست برای AI» | beginner audience |
| Model | مدل | keep «مدل» if context is clear; otherwise «موتور هوش مصنوعی» cautiously | technical accuracy |
| Multimodal | چندوجهی | «با متن، عکس، صدا و ویدیو کار می‌کنه» | name supported media only |
| Fine-tuning | تنظیم دقیق | «آموزش اختصاصی مدل با داده‌های مشخص» | technical audience; avoid oversimplifying |
| RAG | بازیابی تقویت‌شده | «پاسخ‌دادن با اطلاعات و فایل‌های خودت» | only when accurate |
| API | رابط برنامه‌نویسی | keep `API` and explain function if needed | technical identifier |
| Token | توکن | explain as «بخش‌های کوچک متن» only when useful | technical learning |
| Context window | پنجره زمینه | «مقدار اطلاعاتی که مدل یک‌جا می‌تونه در نظر بگیره» | education |
| Hallucination | توهم | «جواب ساختگی یا اشتباه AI» | familiar and concrete |
| Training data | داده آموزشی | «اطلاعاتی که مدل باهاش آموزش دیده» | education |
| Generation | تولید | «ساخت عکس»، «ساخت متن»، «ساخت ویدیو» | name the output |
| Inference | استنتاج | «وقتی مدل جواب یا خروجی می‌سازه» | technical explanation |
| No-code | بدون کدنویسی | keep when true; explain what still requires setup | avoid implying zero effort |
| Integration | یکپارچه‌سازی | «وصل‌کردن دو ابزار»، «ارتباط با سیستم فعلی» | name the systems |

## Common transformation patterns

### Internal process → audience result

Internal:

«سیستم تشخیص و شخصی‌سازی مسیر یادگیری»

Frontstage:

«چند سؤال جواب بده تا ببینی از کجا شروع کنی.»

### Feature → practical outcome

Internal:

«دسترسی به Workflowهای آماده»

Frontstage:

«مراحل آماده‌ای می‌گیری که همون لحظه بتونی اجرا کنی.»

### Category → situation

Internal:

«خدمات اتوماسیون کسب‌وکار»

Frontstage:

«کارهای تکراری کسب‌وکارت رو خودکار کن.»

### Metric → interpretable meaning

Internal:

«Conversion rate: 2.7%»

Frontstage:

«از هر ۱۰۰ نفری که ثبت‌نام کردند، حدود ۳ نفر خریدند.»

### Privacy label → concrete explanation

Internal:

«Analytics consent»

Frontstage:

«با اجازه تو، آمار کلی استفاده از سایت رو بررسی می‌کنیم. اسم و شماره‌ت برای این آمار ارسال نمی‌شه.»

Only use the last claim if the implementation has been verified.
