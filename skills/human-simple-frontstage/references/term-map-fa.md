# Persian Frontstage Term Map

Use this map when source material contains internal terminology. Choose the option that matches the real user situation; do not replace mechanically.

## Core rule

Do not translate the label. Explain the user-facing meaning.

Keep exact identifiers unchanged in code, analytics, APIs, file paths, URLs, database fields, and technical documentation.

## Product and UX

| Backstage term | Avoid as default | User-facing options |
|---|---|---|
| Diagnostic | تشخیص هوشمند / دیاگنوستیک | «ببین از کجا شروع کنی»، «چند سؤال برای شناخت تو»، «اول ببینیم چی به دردت می‌خوره» |
| Personalization | شخصی‌سازی | «متناسب با نیاز تو»، «برای خودت»، «براساس جواب‌های تو» |
| Onboarding | آنبوردینگ / ورود اولیه | «شروع کار»، «قدم‌های اول»، «بیا از اینجا شروع کنیم» |
| Activation | فعال‌سازی کاربر | «اولین قدمت رو بردار»، «شروعش کن»، «اولین کار رو انجام بده» |
| User journey | سفر کاربر | «مراحل کار»، «از ورود تا نتیجه»، «راهی که کاربر طی می‌کنه» |
| Flow | فلو | «مراحل»، «روال»، «روند» |
| Feature | فیچر / قابلیت | نتیجه یا کاری که کاربر می‌تواند انجام دهد |
| Flagship offer | پیشنهاد پرچم‌دار | «برنامه اصلی»، «آموزش اصلی»، نام واقعی محصول |
| Tier | سطح / تیر | «پلن»، «انتخاب»، یا تفاوت واقعی هر گزینه |

| Retention | حفظ کاربر | «ادامه‌دادن»، «برگشتن»، «نیمه‌کاره رها نکردن» |
| Drop-off | ریزش | «کاربرها کجا ادامه نمی‌دن؟» |
| Empty state | حالت خالی | «وقتی هنوز چیزی اینجا نیست» |
| Progressive disclosure | افشای تدریجی | «اطلاعات رو کم‌کم نشون بده» |

|---|---|

| Authentication | «ورود و تأیید هویت» |
| API | explain the service connection only when needed |
| Backend | «بخش پشت سایت» only in support or technical education |

## Selection rules

1. Use the concrete destination or action when possible.
2. Use the audience’s own vocabulary when verified.
3. Keep a known English product name when translating it would confuse more.
4. Explain an unfamiliar English term once if it must remain.
5. Do not expose backstage terms merely to sound expert.
6. Do not replace exact code identifiers inside code blocks, schemas, events, or file paths.
