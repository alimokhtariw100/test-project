# Quality Gates

Use these gates before approving any audience-facing Persian copy.

## How to score

Score each gate:

- `0` = fails
- `1` = partly works or needs context
- `2` = passes clearly

A string is publishable only when:

- Truth and Meaning both score `2`
- No mandatory gate scores `0`
- Total score is at least `15/18`

Do not average away a factual, legal, or safety failure.

## 1. Truth gate — mandatory

Check:

- Is every claim supported by the actual product, source, or evidence?
- Does the destination really do what the button says?
- Are price, timing, capacity, availability, and guarantees exact?
- Did simplification hide uncertainty or a condition?

Automatic fail:

- promising an unbuilt feature
- turning an estimate into certainty
- implying guaranteed income, health, legal, or immigration outcomes
- sending a CTA to a dead or unrelated route

## 2. Meaning gate — mandatory

Check:

- Did the core idea survive the rewrite?
- Did any exception that changes the user’s decision disappear?
- Is the relationship between cause, action, and result still correct?

Shorter is not better when it changes the decision.

## 3. Three-second gate

Show only the final string and ask:

- Can the intended audience explain it after one quick read?
- Can they tell what this section is about?
- For a button, can they predict what happens next?

If the user must decode a metaphor, internal term, or long setup, fail it.

## 4. Class-five gate

Check whether a person without professional knowledge can understand it.

Do not literally write for a child. Keep adult dignity, but remove assumed expertise.

Bad:

«فرایند فعال‌سازی و شخصی‌سازی تجربه یادگیری»

Better:

«چند سؤال جواب بده تا بفهمیم از کجا شروع کنی.»

## 5. Speech gate

Read the copy aloud.

Check:

- Does it sound like a real Persian speaker?
- Is the word order natural?
- Would the chosen brand voice actually say it?
- Are there translated-English structures or bureaucratic phrases?

If it sounds written by a committee or machine, rewrite it.

## 6. Action gate

For actionable surfaces, check:

- Is the immediate next step clear?
- Does the verb match the destination?
- Does the user know whether they will watch, buy, submit, call, download, or continue?

Bad:

«ادامه»

Better:

«آموزش رو ببین»

Use a generic label only when the surrounding context makes the action unmistakable.

## 7. Dignity gate

Check:

- Is the copy simple without sounding childish?
- Does it avoid talking down to the user?
- Does it avoid cheap hype, forced slang, and manipulative pressure?
- Does it preserve professional authority?

Simple language should increase trust, not reduce it.

## 8. Mobile gate

Check the string at the real mobile width.

- Can it be scanned without a paragraph wall?
- Does the headline keep its intended emphasis?
- Is the button label short enough?
- Does a line break split a name, number, or meaning awkwardly?
- Is the most important phrase visible before the user scrolls?

Do not approve copy only from a desktop preview.

## 9. Brand gate

Check:

- Could this text belong to a hundred unrelated brands?
- Does it express the project’s actual point of view?
- Is a signature word being repeated until it becomes empty?
- Does it match the project’s selected level of warmth, formality, and authority?

Generic correctness is not enough for a founder brand.

## Accessibility checks

Also verify:

- link and button labels make sense outside visual context
- error messages identify the field or problem
- instructions do not rely only on color, position, or icon shape
- abbreviations and unfamiliar English terms are explained when necessary
- the text does not require hover to understand the action

## Fast review card

Before publishing, answer:

```text
FACTUALLY TRUE?       YES / NO
MEANING PRESERVED?    YES / NO
UNDERSTOOD IN 3 SEC?  YES / NO
NATURAL WHEN SPOKEN?  YES / NO
NEXT ACTION CLEAR?    YES / NO / N-A
RESPECTFUL?           YES / NO
MOBILE-SCANNABLE?     YES / NO
BRAND-SPECIFIC?       YES / NO
```

Any `NO` on truth or meaning blocks publication.
